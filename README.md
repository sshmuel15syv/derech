# מפת הדרך שלי

דף לניהול פרויקטים, שלבים, משימות וסדר יום, עם שיחה עם Claude שמשנה את התוכנית.
עובד בכרום במחשב ובטלפון. הנתונים נשמרים בגוגל שיטס שלך, והשיחה עוברת דרך אפליקציית Claude שלך.

## הגדרה חד-פעמית (כ-10 דקות)

### 1. הגיליון
1. פתח גיליון חדש ב-Google Sheets ותן לו שם, למשל "מפת הדרך".
2. בתפריט: **Extensions → Apps Script**.
3. מחק את מה שיש שם, והדבק את כל התוכן של הקובץ `apps-script.gs` (קיבלת אותו בנפרד, הוא לא נמצא בריפו כי יש בו את הפרויקטים שלך).
4. בשורה `const SECRET = 'CHANGE-ME';` החלף את `CHANGE-ME` בקוד סודי משלך (מילים ומספרים, בלי רווחים). שמור (Ctrl+S).
5. **Deploy → New deployment**. בגלגל השיניים בחר **Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
6. לחץ Deploy ואשר את ההרשאות. גוגל תציג אזהרה ("Google hasn't verified this app"): לחץ Advanced ← Go to … (unsafe). זה הסקריפט שלך, הוא לא נשלח לאף אחד.
7. העתק את ה-**Web app URL** (מסתיים ב-`/exec`).

"Anyone" אומר שכל מי שיש לו את הכתובת יכול לפנות לסקריפט, אבל בלי הקוד הסודי הוא לא יקבל ולא ישנה כלום.

### 2. השיחה עם Claude
השיחה עוברת דרך אפליקציית Claude הרגילה שלך, בלי תשלום נוסף:
1. בלשונית "שיחה" כותבים מה לשנות ולוחצים על החץ. הבקשה, יחד עם כל התוכנית, מועתקת.
2. לוחצים "פתח את Claude", מדביקים בשיחה חדשה ושולחים.
3. מעתיקים את כל התשובה של Claude, חוזרים לדף, מדביקים ולוחצים "ביצוע השינויים".

(לא חובה: אם תכניס מפתח API של Anthropic בהגדרות, השיחה תעבוד ישירות מתוך הדף, בתשלום לפי שימוש.)

### 3. בכל מכשיר (מחשב וטלפון)
1. פתח את הדף בכרום.
2. בחלון ההגדרות (או בגלגל השיניים למעלה) הדבק את כתובת ה-`/exec` ואת הקוד הסודי. את שדה מפתח ה-API אפשר להשאיר ריק.
3. בטלפון: בכרום לחץ על שלוש הנקודות ← **הוספה למסך הבית**.

הערכים נשמרים רק בדפדפן של אותו מכשיר. הם לא נמצאים בקוד ולא בגיליון.

## אם משנים את הסקריפט
אחרי כל שינוי ב-Apps Script: **Deploy → Manage deployments → עריכה (עיפרון) → Version: New version → Deploy**. הכתובת נשארת אותה כתובת.
